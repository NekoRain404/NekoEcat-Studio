# utils/ — Utility Functions

Reusable helper functions for table manipulation, text formatting,
UI widget creation, and documentation generation.

## Files

| File | Purpose |
|------|---------|
| `Documentation` | Help/about dialog content generation |
| `TableHelpers` | QTableWidget cell creation and formatting |
| `TextHelpers` | String formatting and localization utilities |
| `UiHelpers` | Widget creation, styling, and layout helpers |
