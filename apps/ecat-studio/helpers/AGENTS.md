# helpers/ — Reusable Utilities

Stateless helper functions used across the GUI. No domain logic.

## Files

| File | Purpose |
|------|---------|
| `StudioDocumentation` | HTML strings for the built-in manual and about dialog |
| `StudioTableHelpers` | `QTableWidget` utilities: row selection, CSV, markdown |
| `StudioTextHelpers` | Hex normalization, value decoding, address display |
| `StudioUiHelpers` | Widget factories: section titles, metric cards, labels |
